# Guía del curso de YouTube

## Propósito

Construir Personal Desktop Hub por entregas pequeñas y enseñar cómo planificar, desarrollar y verificar una aplicación real con Codex.

## Estructura sugerida de cada episodio

- Objetivo y comportamiento esperado.
- Fase activa y estado del repositorio.
- Plan de trabajo y archivos afectados.
- Implementación y revisión con Codex.
- Demostración de la función ejecutándose.
- Verificaciones realizadas y resultado observado.
- Limitaciones, decisiones y siguiente episodio.

## Reglas editoriales

- Diferenciar una propuesta, una maqueta y una función terminada.
- No afirmar que algo fue probado si no se ejecutó.
- Mostrar qué datos procesa el widget de correo y qué permisos solicita cada integración.
- Dejar claro que el asistente es opcional.
- Ocultar credenciales, códigos de acceso, mensajes privados y datos personales durante las grabaciones.
- Relacionar cada episodio con el commit o etiqueta correspondiente.
