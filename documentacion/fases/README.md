# Plan general por fases

Cada fase tiene un documento propio con objetivo, entregables, dependencias y criterios de cierre. Una función solo se considera completa cuando trabaja en la aplicación; una representación visual no basta.

| Fase | Documento | Tema |
| --- | --- | --- |
| 0 | [Arquitectura y estructura](fase-0-arquitectura.md) | Stack aprobado, solución y límites entre proyectos. |
| 1 | [Prototipo y ventanas](fase-1-prototipo.md) | Ventana base, navegación y estilos iniciales. |
| 2 | [Lanzador y barras](fase-2-lanzador-y-barras.md) | Carrusel, barra del Hub y trabajo de compatibilidad con barra de tareas Windows. |
| 3 | [Widgets y correo](fase-3-widgets-y-correo.md) | Barra lateral, widgets y visualización de correo. |
| 4 | [Calendario, notas y tareas](fase-4-productividad.md) | Módulos de productividad y persistencia local. |
| 5 | [Recordatorios y correo](fase-5-notificaciones.md) | Hábitos, notificaciones del sistema y avisos de correo. |
| 6 | [Asistente y personalización](fase-6-asistente-y-personalizacion.md) | Asistente optativo y preferencias individuales. |
| 7 | [Docker y API opcional](fase-7-docker-api.md) | Compose, ASP.NET Core y PostgreSQL. |
| 8 | [Calidad y publicación](fase-8-calidad-y-publicacion.md) | Compatibilidad, instalador, documentación y portafolio. |
