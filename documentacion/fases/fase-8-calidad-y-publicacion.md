# Fase 8: calidad y publicación

## Objetivo

Preparar el producto para demostración, portafolio e instalación en Windows 11.

## Trabajo

- Verificar DPI, más de un monitor, cierre completo y ejecución desde bandeja.
- Revisar uso de memoria y comportamiento en reposo.
- Automatizar compilación y verificaciones en GitHub Actions.
- Crear instalador y guías de instalación, uso, copia y recuperación de datos.
- Publicar capturas y resultados de cada fase junto a los episodios del curso.

## Criterio de cierre

Un usuario puede instalar, ejecutar y desinstalar la aplicación siguiendo instrucciones documentadas y conserva acceso a sus datos locales.
