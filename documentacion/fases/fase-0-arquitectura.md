# Fase 0: arquitectura y estructura

## Objetivo

Fijar las decisiones iniciales y preparar la solución de .NET con límites claros antes de implementar funciones.

## Trabajo

- Usar C#, .NET 10 LTS, WPF/XAML y MVVM para el cliente Windows.
- Separar App, Application, Core e Infrastructure; reservar Api como componente opcional.
- Definir SQLite/EF Core para persistencia local.
- Crear estructura Docker para API/PostgreSQL en fase posterior.
- Documentar alcance, privacidad, ambos tipos de barra y conexiones opcionales.

## Entregable

Solución inicial documentada, estructura de proyectos y decisiones ADR; aún no incluye módulos funcionales.

## Criterio de cierre

Los documentos de alcance, tecnologías, estructura y fases concuerdan entre sí y definen qué queda fuera de la primera versión.
